# 第一轮作业收录（非 Java 语言）

Java 路线第一轮作业提交到 [west2-online-reserve/collection-java](https://github.com/west2-online-reserve/collection-java) 的 [`work2/`](https://github.com/west2-online-reserve/collection-java/tree/main/work2) 目录，具体方式按该仓库说明执行，不在本目录收录。

本目录由负责人统一收录采用其他语言（如 Go）的第一轮作业。每位同学使用自己的 GitHub ID 作为子目录名，具体提交入口和收录方式以当届负责人通知为准；无需为第一轮另建独立项目仓库。

```text
work1/
├─README.md
└─<GitHub ID>/
   ├─README.md
   ├─源代码与构建配置
   └─测试与必要数据
```

每份作业应能独立运行。README 写清所用语言、环境版本、运行和测试方式；保留源码、依赖配置、测试及数据。Java 赛事查询任务的数据由学习者自行抓取，还需包含抓取脚本、本地 JSON 数据快照，并说明数据来源与抓取时间。不要只提交截图、jar 或可执行文件，也不要包含密钥、token、个人敏感信息、IDE 缓存和构建产物。

第一轮建议亲手编写主要代码，练习语法、调试、测试和异常处理。任务说明：[Java](../docs/1-基础语法-java.md) / [Go](../docs/1-基础语法-go.md)。

第二轮及后续项目由学生自行创建独立的个人公开仓库，在个人仓库持续迭代并提交链接，不在本目录收录源码。完整规则见[考核文档导航](../docs/README.md)。
